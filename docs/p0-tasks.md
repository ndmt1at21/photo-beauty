## Cách phối hợp

- **Lead và agent:** phiên chính của bạn là lead: giao task theo mục Thứ tự, mỗi agent một task trong một worktree riêng (`.claude/worktrees/<mã task>`, nhánh `p0/<mã>`), như các worktree của snapone. Khi giao, ghi "(đang làm: worktree `<mã>`, ngày)" vào dòng task.
- **Chỉ sửa file của task** (phần "file" trong ngoặc sau tên task). Cần sửa file khác thì hỏi lead; lead chỉ cho khi không task đang chạy nào giữ file đó. File đi qua nhiều task mỗi lúc chỉ một task giữ, theo thứ tự: `core/tile.*` A1 → K1 → E4; `core/gpu_composite.*` B2 → B3; `core/pbd.cpp` M2 → M3; `ui/canvas.*` V1 → V2 → C3; `ui/qml/Main.qml` R1b → V1 → U1 → C3 → U3; `.github/workflows/ci.yml` R2 → U1 → E3.

- **Hợp đồng:** `core/tile.h`, `core/doc.h`, `core/render.h`, `core/stroke.h` (A1) là hợp đồng giữa các task. Thêm hàm thì cứ thêm. Đọc, ghi dữ liệu ô luôn qua `pin()` (RAII) ngay từ đầu: A1 cài bản luôn nằm trong RAM, K1 cài nén, đẩy ra đĩa sau cùng API.
